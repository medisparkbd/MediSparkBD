বাংলা MCQ — উত্তর শুধু লেবেল (ক / খ / গ / ঘ) লিখুন

১। কোনটির পুচ্ছ পাখনা হেটারোসার্কাল ধরনের? [ঢা. বো. ১৯]
(ক) রুই
(খ) লাংফিশ
(গ) টাকি
(ঘ) হাঙ্গর
সঠিক উত্তর: ঘ

২। সম্পূর্ণ চার প্রকোষ্ঠবিশিষ্ট হৃৎপিণ্ড কোন প্রাণীতে দেখা যায়? [ঢা. বো. ১৯]
(ক) টিকটিকি
(খ) কুমির
(গ) কচ্ছপ
(ঘ) সাপ
সঠিক উত্তর: খ

৩। ত্রিপদ নামকরণের প্রবক্তা কোন বিজ্ঞানী? [চ. বো. ১৯]
(ক) লিনিয়াস
(খ) স্লেজেল
(গ) ল্যামার্ক
(ঘ) হ্যাক্সেলে
সঠিক উত্তর: খ
  • প্রশ্ন নম্বর: ১। ২। … অথবা 1. 2) Q1.
  • অপশন: (ক) (খ) (গ) (ঘ) অথবা ক. খ. গ. ঘ. অথবা A. B. C. D.
  • উত্তর: শুধু লেবেল — সঠিক উত্তর: ঘ / উত্তর: খ / Answer: D
  • বোর্ড ট্যাগ প্রশ্নের লাইনেই রাখুন: [ঢা. বো. ১৯] — সমস্যা নেই।
  • প্রশ্নগুলোর মাঝে এক লাইন ফাঁকা রাখুন।
✗ ভুল ফরম্যাট (এইভাবে paste করবেন না)

উত্তরের সাথে ব্র্যাকেটে অপশন-টেক্সট লিখবেন না

সঠিক উত্তর: (ঘ) হাঙ্গর     ← ভুল
সঠিক উত্তর: ঘ              ← সঠিক
  • সঠিক উত্তর: (ঘ) হাঙ্গর — এই ফরম্যাটে উত্তর detect হয় না, আর বড় সেটে (১১টার পর) প্রশ্নও ভাগ হয়ে যায়।
  • উত্তরের লাইনে শুধু এক অক্ষরের লেবেল রাখুন — অপশনের টেক্সট আবার লিখবেন না।
  • প্রশ্নের মাঝখানে Answer Key: / উত্তরমালা হেডিং দেবেন না (থাকলে শেষের অংশ আলাদা answer-key ধরা হয়)।
ⓘ আলাদা Answer Key (নতুন সুবিধা)

প্রশ্নে উত্তর না থাকলে — Answer source: “Separate”

  • প্রশ্ন paste করে Detect করুন (উত্তর খালি থাকবে)।
  • Answer Key ঘরে key paste করুন — ফরম্যাট: 1-A 2-B … অথবা 1. A 2. B … অথবা 1 A 2 B … অথবা 1A 2B 3C
  • Detect Answer Key → preview-তে মিলিয়ে দেখুন (✓ Matched / ⚠ Missing / Extra) → Apply Answer Key → Save।
  • মিল হয় প্রশ্ন নম্বর দিয়ে (২৫→B মানে ২৫ নম্বর প্রশ্নের উত্তর B) — ৫০/১০০+ key-ও একসাথে সাপোর্ট করে।
  • Answer-key ছবি থাকলে Upload Answer Key Image দিয়েও detect করা যায়।
